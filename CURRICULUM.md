# 📚 30-Day JavaScript Curriculum

Each day = **theory + exercise**. Mark days as done with ✅ as you go.

## Week 1 — Fundamentals

- [ ] **Day 1** — Setup & Hello World: browser console, `<script>` tag, `console.log`. _Exercise: your first script._
- [ ] **Day 2** — Variables & Constants: `let`, `const`, naming rules. _Exercise: profile card data._
- [ ] **Day 3** — Data Types: strings, numbers, booleans, `null`, `undefined`. _Exercise: type explorer._
- [ ] **Day 4** — Operators & Type Conversion: arithmetic, comparison, `==` vs `===`. _Exercise: unit converter._
- [ ] **Day 5** — Strings & Template Literals: methods, backticks, interpolation. _Exercise: mad-libs generator._
- [ ] **Day 6** — Conditionals: `if/else`, ternary, `switch`. _Exercise: grade calculator._
- [ ] **Day 7** — Loops: `for`, `while`, `for...of`, `break/continue`. _Exercise: multiplication table._

## Week 2 — Functions & Data Structures

- [ ] **Day 8** — Functions: declarations, expressions, parameters, return. _Exercise: tip calculator._
- [ ] **Day 9** — Arrow Functions & Scope: `=>`, block vs function scope. _Exercise: refactor day 8._
- [ ] **Day 10** — Arrays I: creation, indexing, `push/pop/shift/unshift`. _Exercise: todo list (console)._
- [ ] **Day 11** — Arrays II: `map`, `filter`, `reduce`, `find`. _Exercise: data processing pipeline._
- [ ] **Day 12** — Objects: properties, methods, destructuring. _Exercise: library of books._
- [ ] **Day 13** — Spread, Rest & Immutability: `...`, `Object.assign`. _Exercise: state updater._
- [ ] **Day 14** — Closures & Recursion (intro). _Exercise: counter factory._

## Week 3 — DOM & Browser

- [ ] **Day 15** — DOM Basics: `querySelector`, changing text/styles. _Exercise: color switcher._
- [ ] **Day 16** — Creating & Removing Elements. _Exercise: dynamic list._
- [ ] **Day 17** — Events: `addEventListener`, event object. _Exercise: interactive button demo._
- [ ] **Day 18** — Forms & Validation: inputs, `submit`, basic validation. _Exercise: signup form._
- [ ] **Day 19** — Mini Project: **Todo App** (localStorage). 
- [ ] **Day 20** — Timers & Intervals: `setTimeout`, `setInterval`. _Exercise: countdown timer._
- [ ] **Day 21** — Mini Project: **Pomodoro Timer**.

## Week 4 — Async, ES6+ & Final Project

- [ ] **Day 22** — Promises: `then/catch`, creating promises. _Exercise: simulated API._
- [ ] **Day 23** — `async/await` & Fetch API. _Exercise: random user fetcher._
- [ ] **Day 24** — Working with APIs: JSON, HTTP status codes. _Exercise: weather widget._
- [ ] **Day 25** — Error Handling: `try/catch`, custom errors. _Exercise: safe calculator._
- [ ] **Day 26** — ES6+ Features: modules, optional chaining, nullish coalescing. _Exercise: refactor old days._
- [ ] **Day 27** — Array/Object Deep Dive: sorting, grouping, iteration patterns. _Exercise: data dashboard._
- [ ] **Day 28** — Mini Project: **Movie/Book Search App** (public API).
- [ ] **Day 29** — Final Project day 1: build **your own app** from scratch.
- [ ] **Day 30** — Final Project day 2: polish, README, deploy (GitHub Pages). 🎉

## Tips

- Write code every day, even if it's 20 minutes.
- Don't copy-paste solutions — type everything by hand.
- Commit daily: `git commit -m "Day 12: objects exercise"`.
- Stuck for 30+ minutes? Ask me — that's what I'm here for. 😉
