# JavaScript in 30 Days 🚀

A structured 30-day journey to learn JavaScript from the ground up.
Each day combines **theory + a small hands-on exercise**, so by the end you'll have
both solid fundamentals and 30 mini-projects in your portfolio.

## Why this project?

- ✅ **Consistent** — small daily steps, no burnout
- ✅ **Practical** — every day ends with code you actually wrote
- ✅ **Public** — learning in the open keeps you accountable

## How it works

1. Open the current day in [`CURRICULUM.md`](./CURRICULUM.md)
2. Read the theory (1–2 hours max)
3. Complete the day's exercise in `days/day-XX/`
4. Commit your progress 🎉

## Curriculum overview

| Week | Focus |
|------|-------|
| 1 | Fundamentals: variables, types, operators, control flow |
| 2 | Functions, arrays, objects, scope, closures |
| 3 | DOM, events, browser APIs, async basics |
| 4 | Fetch API, ES6+, error handling, final project |

The full day-by-day plan lives in [`CURRICULUM.md`](./CURRICULUM.md).

```bash

```
